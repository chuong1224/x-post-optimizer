## English

### Overview

This skill activates when you upload a fantasy character image or video and ask to write a short, optimized English X post to maximize reach. It analyzes visuals, matches character titles, and generates posts following a proven high-engagement structure.

**Trigger phrases:** "viet post X", "viet post tieng Anh ngan gon", "toi uu reach", "optimize X post", "ngan gon hon".

### Purpose

Turn fantasy visuals into concise, reply-weighted X posts that perform well in the algorithm (strong hooks + emotional questions + clear CTA).

### Workflow

1. **Visual Analysis** — Extract key details (appearance, outfit, weapons, effects, vibe).
2. **Character Title** — Match or generate fitting title (e.g. Crimson Sakura Onna, Lightning Seraph).
3. **Generate Post** — Follow strict 5-line structure + character limit (≤280 chars).
4. **Shorten if needed** — Keep structure, only trim secondary details.
5. **Output** — Return only the raw post text.

### Key Features

- Strict visual-to-title matching system
- Proven high-engagement post structure
- Multiple hook & question templates
- Character limit aware (≤280 chars)
- "Shorten further" mode while preserving CTA
- No meta comments in output

### Examples

See `SKILL.md` for full examples (Full / Shortened / Ultra-short versions).

### Gotchas

- Count line breaks as ~4 chars each
- Use vibe-matching emojis only
- Never remove the final CTA line
- Always personalize the question with strong verbs
- Output raw post text only

## Tiếng Việt

### Tổng quan

Skill này được kích hoạt khi bạn upload ảnh hoặc video nhân vật fantasy và yêu cầu viết post X tiếng Anh ngắn gọn, tối ưu reach. Nó phân tích visual, gắn character title và tạo post theo cấu trúc đã chứng minh hiệu quả cao.

**Cụm từ kích hoạt:** "viet post X", "viet post tieng Anh ngan gon", "toi uu reach", "ngan gon hon".

### Mục đích

Biến hình ảnh/video fantasy thành post X ngắn gọn, tối ưu tương tác reply (tín hiệu mạnh nhất trong X algorithm).

### Quy trình

1. **Phân tích Visual** — Trích xuất ngoại hình, trang phục, vũ khí, hiệu ứng, vibe.
2. **Chọn Character Title** — Khớp hoặc tự ghép title phù hợp.
3. **Tạo Post** — Áp dụng cấu trúc 5 dòng + giới hạn 280 ký tự.
4. **Rút gọn nếu cần** — Giữ nguyên cấu trúc, chỉ cắt chi tiết phụ.
5. **Output** — Chỉ xuất raw post text.

### Tính năng nổi bật

- Hệ thống ghép character title thông minh
- Cấu trúc post đã chứng minh tăng reach
- Nhiều template hook & câu hỏi
- Ý thức giới hạn ký tự (≤280)
- Chế độ "ngắn gọn hơn" giữ nguyên CTA
- Output chỉ raw post text, không meta

### Ví dụ

Xem `SKILL.md` để có các phiên bản Full / Shortened / Ultra-short.

### Lưu ý quan trọng

- Đếm line break ~4 ký tự
- Dùng emoji phù hợp vibe
- Không được xóa dòng CTA cuối
- Câu hỏi phải cá nhân hóa + động từ mạnh
- Chỉ xuất raw post text
